📱 Passo a passo detalhado do operador

1. Preparar os arquivos

Toque no ZIP da Etapa 1 e extraia usando o gerenciador de arquivos do Android. Entre na pasta extraída. O arquivo principal precisa se chamar index.html. Não renomeie os arquivos técnicos.

2. Criar o projeto no GitHub

Abra github.com, entre ou crie sua conta. Toque no sinal + e escolha New repository. Nome: agenda-metal-dekor. Selecione Public, crie o repositório e não adicione arquivos de modelo que possam confundir o envio.

3. Fazer upload pelo celular

No repositório, escolha Add file → Upload files. No seletor Android, navegue até a pasta extraída. Envie os três arquivos da raiz e a pasta icons com as duas imagens PNG. Se a interface móvel não mostrar upload de pasta, crie a pasta icons pelo site e envie os PNGs nela, ou use a opção de solicitar site para computador no navegador. Finalize em Commit changes.

4. Ativar o GitHub Pages

No repositório, entre em Settings → Pages. Em Source/Build and deployment, escolha Deploy from a branch. Selecione branch main, pasta /(root) e salve. Aguarde a publicação. O endereço normalmente segue este formato:

https://SEU-USUARIO.github.io/agenda-metal-dekor/

Substitua SEU-USUARIO pelo seu nome de usuário do GitHub. Não adivinhe o endereço: copie o link exibido em Settings → Pages.

5. Conferir o site

Abra o endereço publicado no Chrome. Se aparecer 404, confira se o arquivo index.html está na raiz do repositório e se o Pages aponta para main / root. Aguarde alguns minutos e tente novamente. Para instalar a PWA diretamente, use o menu do Chrome → Instalar app ou Adicionar à tela inicial, se essa opção aparecer.

6. Empacotar como APK

Abra pwabuilder.com, cole o endereço HTTPS publicado e inicie a análise. Vá para Package for stores → Android → Other Android. Confira nome do app Agenda Metal Dekor e identificador sugerido br.com.metaldekor.agenda (se o serviço aceitar). Gere o pacote e baixe o ZIP resultante. Procure o arquivo .apk dentro dele.

A interface e as opções do PWABuilder podem mudar. Se só aparecer AAB ou pacote para Google Play, volte e selecione Other Android; o AAB é voltado à publicação na loja e não é o APK direto esperado para esta etapa.

7. Instalar com segurança

Abra o APK que você mesmo gerou. Leia a tela de confirmação do Android. Se for necessário, permita temporariamente a instalação para o aplicativo usado para abrir o arquivo. Não instale APK recebido de desconhecidos. Depois da instalação, você pode revogar essa permissão nas configurações do Android.

🧪 Checklist de aceite — Etapa 1

  • O aplicativo abre sem tela de erro.
  • As abas Início, Tarefas, Serviços, Orçamentos, Clientes, Financeiro e Equipe funcionam.
  • Um registro fictício pode ser criado e permanece após fechar e abrir o app.
  • Backup exporta um arquivo JSON.
  • Restauração de um backup de teste funciona.
  • O app abre depois de já ter sido carregado uma vez, mesmo sem internet (dependendo do cache e do estado do aparelho).
  • Está claro para os usuários que os dados são locais e não sincronizam entre celulares.

🛟 Problemas comuns

Site 404: confira o nome index.html, branch main e pasta root no Pages.

PWABuilder não reconhece a PWA: abra o site pelo HTTPS, confirme manifest.webmanifest e ícones 192/512, atualize a página e rode a análise novamente.

APK mostra barra do navegador: algumas configurações TWA dependem de Digital Asset Links. Para teste inicial, confirme se o pacote Other Android oferece fallback adequado; a configuração de assetlinks pode exigir etapa adicional.

Dados sumiram: confira se abriu exatamente o mesmo endereço/origem e se o armazenamento do app não foi apagado. Use backup JSON regularmente. O modo anônimo não é apropriado para uso normal.
